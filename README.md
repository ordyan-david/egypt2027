# Египет 2027

Готовый сайт о путешествии четырёх друзей: **Хургада → Луксор → Каир**. Два варианта дат переключаются прямо на странице:

| Вариант | Поездка | Прибытие домой в Воронеж |
|---|---|---|
| А | 6–14 февраля 2027 | Утром 15 февраля |
| Б | 7–15 февраля 2027 | Утром 16 февраля |

В каждом варианте **9 календарных дней и 8 ночей в Египте**: 3 в Хургаде, 1 в Луксоре, 4 в Каире. Утром 6 или 7 февраля — сидячий поезд Воронеж → Москва, ориентир прибытия около 14:00; затем переезд в аэропорт и подходящий вечерний рейс. Обратно — прилёт в Москву вечером 14 или 15 февраля, ночной поезд и утро дома. Конкретные поезда, авиарейсы и стыковки ещё нужно подобрать.

Ориентир — **105 000 ₽ на человека / 420 000 ₽ на четверых** для обоих вариантов. Жильё — 13 500 ₽, еда — 7 200 ₽, резерв — 5 100 ₽. Экономия 2 300 ₽ от сокращения поездки перенесена в резерв. Фактические цены билетов и жилья для разных дат могут различаться.

## Открыть на Mac

Нужен Node.js 20 или новее; проверки на GitHub используют Node.js 24. Устанавливать npm-пакеты и собирать сайт не требуется.

1. Распакуй архив.
2. В Терминале набери `cd ` с пробелом, перетащи папку проекта в окно и нажми Enter.
3. Выполни `npm run dev`.
4. Открой [http://localhost:3000](http://localhost:3000). Остановка — **Ctrl + C**.

Если порт занят: `PORT=3001 npm run dev`, затем `http://localhost:3001`. Для модулей JavaScript нужен HTTP-сервер: двойной клик по `index.html` не заменяет этот запуск.

## Загрузить на GitHub через браузер

1. На GitHub выбери **New repository**, задай имя проекта и **Public**. Для первой загрузки не добавляй автоматически README: он уже есть в архиве. Создай репозиторий.
2. Выбери **Add file → Upload files**; в пустом репозитории можно воспользоваться ссылкой **uploading an existing file**.
3. В Finder зайди внутрь распакованной папки. Нажми **Cmd + Shift + .**, чтобы показать скрытые файлы и папку `.github`.
4. Перетащи **содержимое папки проекта** в окно загрузки и сохрани через **Commit changes** в ветку `main`.
5. Проверь, что в корне репозитория видны `dist/`, `scripts/`, `tests/`, `package.json` и **`.github/workflows/pages.yml`**. Дополнительная внешняя папка с именем архива не нужна.

Основная ветка должна называться `main`. Если GitHub создал другую, переименуй её в `main` перед настройкой Pages.

**Сам ZIP загружать не нужно:** GitHub не распакует его для публикации сайта. Если скрытая папка `.github` не загрузилась, создай файл через **Add file → Create new file**, укажи полное имя `.github/workflows/pages.yml` и вставь содержимое этого файла из проекта.

## Опубликовать и получить ссылку

1. В репозитории открой **Settings → Pages**.
2. В **Build and deployment → Source** выбери **GitHub Actions**. Готовый workflow уже включён в проект.
3. Во вкладке **Actions** открой **Publish Egypt 2027**. Запусти **Run workflow** для `main`, если после настройки ещё нет успешного запуска. Если первый запуск успел завершиться до включения Pages, повтори его через **Re-run all jobs**.
4. Дождись зелёного результата у `test` и `publish`.
5. Открой адрес из **Settings → Pages** или успешного deployment. Это ссылка для друзей; проверь её в приватном окне браузера.

Workflow проверяет проект и публикует **только `dist/`**. После каждого изменения в `main` сайт обновляется автоматически. Pull request запускает проверки без публикации. Вручную введённые секреты для Pages не нужны.

Официальные инструкции: [настройка источника Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [публикация через GitHub Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages). Бесплатный вариант Pages подходит для публичного репозитория.

## Альтернатива: загрузить через Git

Для нового пустого репозитория вместо загрузки через браузер выполни из папки проекта:

```bash
git init
git add .
git commit -m "Создать сайт Египет 2027"
git branch -M main
```

Скопируй адрес своего репозитория из **Code → HTTPS**. Выполни `git remote add origin`, добавив через пробел **этот реальный адрес**, затем:

```bash
git push -u origin main
```

При запросе входа используй настроенную GitHub-аутентификацию. Обычный пароль аккаунта для Git по HTTPS не подходит; варианты описаны в [документации GitHub](https://docs.github.com/en/get-started/git-basics/about-remote-repositories#cloning-with-https-urls). Не записывай токены в проект. Если Git просит автора, задай `git config user.name "Твоё имя"` и `git config user.email "Твой email"`, затем повтори commit. Если `origin` уже существует, проверь `git remote -v` и используй `git remote set-url origin` с нужным адресом.

## Файлы и изменения

В `dist/` находятся обычные HTML, CSS и JavaScript — исходники одновременно являются готовым сайтом. Все локальные пути относительные и подходят для адреса GitHub Pages с подпапкой проекта.

| Файл | Что редактировать |
|---|---|
| `dist/index.html` | Структура и основной текст |
| `dist/data.js` | Даты, программа, смета, справочная информация |
| `dist/styles.css` | Оформление и адаптивность |
| `dist/app.js` | Карта, вкладки и переключатели |
| `dist/logic.js` | Расчёты, календарь и текстовый план |
| `dist/assets/` | Фото, шрифты и библиотеки |
| `dist/photo-credits.html`, `PHOTO_CREDITS.md` | Авторы и лицензии фото |
| `.github/workflows/pages.yml` | Проверки и публикация Pages |

После правок проверь сайт локально и выполни `npm test`. Если работаешь через Git: `git add .`, затем `git commit -m "Обновить поездку"` и `git push`. Если меняешь файлы через браузер GitHub, достаточно сохранить commit в `main`.

## Возможности и условия

- Два варианта дат, интерактивная карта с пятью точками, программа по дням и раскрываемые детали.
- Бюджет на одного и четверых, сценарий подорожания билетов, сувениры и пересчёт местных цен по изменяемому плановому курсу.
- Кнопка «Поделиться» сохраняет выбранные даты в ссылке: `?dates=6-14` или `?dates=7-15`. Настройки калькулятора между посетителями не передаются.
- Текстовый план учитывает выбранные даты и бюджет. Календарь содержит 9 дней программы и отдельное десятое событие «Утро дома»; оно не добавляет день в Египте.
- Карта OpenStreetMap требует интернета; при недоступной подложке остаются точки и описания маршрута.

Цены предварительные, бронирований нет. Перед покупкой проверь расписания, запас на переезд между вокзалом и аэропортом, стоимость билетов, жильё, визовые условия и курс валют. Личные сувениры и покупки учитываются отдельно от базовой сметы. Официальные источники приведены на сайте.
